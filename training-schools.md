# Training Schools

Resources and materials from OpenSense training events and workshops.

## Training School on Merging and Application of Opportunistic Rainfall Sensor Data

This content of this training school was:
- Introduction to OS datasets, processing with `pycomlink` and `pypwsqc` and the required python ecosystem
- Merging of OS to rainfall products using `mergeplg`
- nowcasting with `pysteps` using OS data
- Hydrological modelling with OS data
- Mini project work building on the topics covered in the training school

Website: https://indico.kit.edu/e/opensense_training_school_2025

## Training school on software and methods for data processing from opportunistic rainfall sensors

The goal of this workshop was hands-on training on methods, code and data for the processing of opportunistic sensor data (CML, PWS and SML) to derive rainfall information. Main target groups were young researchers (PhD students, Postdocs) in the field of hydrometeorology or professionals (e.g. from meteorological service) who work with hydrometeorological sensor data.
